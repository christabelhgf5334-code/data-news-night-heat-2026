# 不降温的城市

一个关于中国六城 30 年夏夜最低气温变化的单页滚动数据新闻作品。

## 主题

作品把 1995-2024 年夏季日最低气温转化为“热夜”指标，观察北京、上海、广州、重庆、武汉、西安六座城市的夜晚变化，并讨论热夜与睡眠恢复、能源负担和城市公平之间的关系。

## 交互

- 城市切换
- 热夜数 / 平均最低气温指标切换
- 30 年趋势折线
- 六城五年窗口对照
- 城市剖面图
- 92 天逐夜温度带
- 1995-2024 年份滑杆

## 数据

- NASA POWER daily point API
- 参数：T2M_MIN、T2M_MAX
- 时间范围：1995-2024 年 6 月 1 日至 8 月 31 日
- 热夜定义：日最低气温 >= 25°C
